## Ce qu'est Event

Event est un instrument web génératif — un patch modulaire virtuel dont les règles sont écrites à l'avance mais dont le jeu ne se répète jamais. Il tourne dans le navigateur, sans installation, sans dépendance externe. Un seul fichier HTML de ~200Ko.

Ce n'est pas de la musique générée par IA. C'est de la **composition par système** — dans la tradition de Brian Eno, Éliane Radigue, Xenakis. L'algorithme est un interprète. Les règles sont celles de son auteur.

### L'identité Botanica

L'identité sonore d'Event est **Botanica** : organique, vivant, jamais saturé. Comme une forêt — il se passe toujours quelque chose, mais rien n'écrase rien. Des micro-événements constants, des silences habités, du foley naturel synthétisé, des arpèges brefs, des percussions organiques. Le drone est subliminal.

### L'événement physique

En physique relativiste, un événement est un point dans l'espace-temps — non reproductible, unique par définition. Au lancement, le système contacte [random.org](https://www.random.org) pour obtenir du vrai bruit atmosphérique radio, le combine avec un timestamp de précision, et initialise depuis cette graine un état qui n'existera qu'une seule fois.

## Architecture sonore

Event est organisé en couches indépendantes qui coexistent sans se parasiter.

**Le drone** — fondation permanente et sublimale. Cinq oscillateurs sinus à ratios irrationnels (φ, π, e). Ne s'entend pas comme un drone — il est la colle inconsciente.

**Emil·in** — notes longues avec transitoire de corde, harmoniques, saturation paire légère.

**Karplus-Strong** — physical modeling de corde pincée. Court, sec, koto ou pizzicato.

**Arpèges** — fragments de 3 à 8 notes par mouvements conjoints. La langue mélodique naturelle de Botanica.

**Pluck / Archet / Bois / Verre / Voix** — timbres organiques qui dérivent librement selon les poids flottants.

**Piano acoustique / préparé** — physical modeling avec table d'harmonie.

**Percussions organiques** — kick, conga, shaker, wood click, frame drum. Tous synthétisés.

**Foley** — gouttes d'eau, feuilles, galets, craquements. Sons naturels synthétisés.

**Dégradations analogiques** — wow & flutter, hiss, saturation, crépitements. La patine de l'instrument.

## Système harmonique

**102 tonalités** disponibles — les 11 modes sur les 12 toniques, pondérés par affinité Botanica.

| Mode | Probabilité |
|---|---|
| Penta m / Penta M | ~39% |
| Dorien | ~17% |
| Lydien | ~15% |
| Japonaise | ~12% |
| Mixolydien | ~6% |
| Majeur / Mineur | ~7% |
| Phrygien / Lyd. augm. / Locrien | ~4% |

### Transitions par pivot harmonique

Quand Event change de tonalité, il module par **note pivot** — une note appartenant simultanément aux deux gammes. La note pivot est choisie par score de stabilité dans chaque gamme (I=3, V=2.5, III=2...). La transition se déroule en 3 phases : convergence → tenue → ouverture. Aucun clash harmonique possible.

## Poids flottants d'instruments

Plus d'orchestrations rigides. 8 **couleurs flottantes** se blendent continuellement les unes dans les autres sur plusieurs minutes — les probabilités de chaque instrument dérivent en permanence, très lentement. Tous les instruments sont toujours potentiellement présents dès le départ.

---

## Arc dramatique

Event a une mémoire de lui-même à l'échelle de la session. Une courbe d'intensité sur ~10 minutes module les biais probabilistes.

| Segment | Durée | Caractère |
|---|---|---|
| Hook | 0–15s | Dense immédiatement |
| Installation | 15s–2min | L'espace s'établit |
| Respiration | 2–4min | Creux — transitions lentes |
| Remontée | 4–7min | Retour progressif |
| Climax | 7–9min | Densité maximale |
| Dissolution | 9–11min | Retrait |
| Flux libre | 11min+ | Probabiliste pur |

## Interface

**`···`** en bas de l'écran → panneau de contrôle.

**Modes de performance** — normal / expérimental / concert / original ◈

**Contrôles harmoniques** — gamme et tonique, verrouillables pour l'export DAW.

**Export** — WAV 32bit float stéréo ou vidéo 1080p VP9.

**Seed** — identifiant hexadécimal de la session. Notez-le pour retrouver un état de départ.
